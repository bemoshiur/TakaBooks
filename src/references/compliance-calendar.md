## Scope this file will cover
- Monthly: VAT return (Mushak 9.1), TDS and VDS deposit, withholding statements.
- Quarterly and half-yearly obligations, and who they apply to.
- Annual: income tax return, audited accounts, RJSC annual return, trade licence renewal.
- Advance income tax instalments.
- One row per obligation, each carrying: what · who it applies to · statutory due date ·
  primary source · consequence of default (linking to `penalties.md`).
- How the dates shift for a non-standard income year.
- A note on public holidays and the treatment of a deadline falling on a closed day.

## Definition of done
1. Every figure carries a primary-source URL and a "current as of" date.
2. No rate, threshold or deadline is written into this prose. Numbers live in
   `data/rates-AY<year>.toml`; this file explains, cites and routes.
3. Anything that could not be confirmed from a primary source is `verified = false` in the rates
   file and is flagged as unverified here.
4. Statutory terms appear as Bangla ∥ English pairs, so the user can search the NBR portal.
5. Reviewed by a Bangladeshi Income Tax Practitioner or Chartered Accountant before release.
6. This header block is replaced — "Current as of", "Sources" and "Status" all filled in.
